Painel PH Nail Designer

Mude valores e horários do site. As mudanças aparecem em cerca de 1 minuto.

Conexão com o GitHub

Só na primeira vez em cada aparelho. Os dados ficam salvos neste aparelho.

Como gerar o token: veja o README do repositório.

Aviso no topo do site

Opcional. Ex.: "Agenda de novembro aberta" ou "Sem atendimento dia 25". Deixe vazio para não mostrar.

Horários

Toque em "Marcar ocupado" quando um horário for reservado. Ele continua aparecendo para as clientes, mas sem poder escolher.

Serviços e valores

Marque "Combo" para mostrar a etiqueta COMBO. Use as setas para mudar a ordem.

Fotos dos trabalhos

As fotos aparecem no site na seção "Meus Trabalhos". Elas são reduzidas automaticamente e enviadas na hora. Use só fotos de trabalhos feitos por você. A legenda é opcional e é salva ao tocar em "Salvar no site".
